# VineryLeaffix
Disables Vinery's automatic grape-leaf growth around Grapvine Stems. This is a cosmetic feature of Vinery with no vanilla config option to turn it off - this mod removes the behavior via Mixin.  Not affiliated with the Let's Do team. Requires Vinery 1.5.0-1.5.3 to be installed
